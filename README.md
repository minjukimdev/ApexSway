# ApexSway

ApexSway enables real-time data processing and auto-scaling for dynamic loads on a cloud-based, highly scalable platform system.

ApexSway is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ApexSway.git`
2. `cd ApexSway`
3. Install in editable mode: `pip install -e .`

## Configuration

ApexSway is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
